# Anotador Ling

Plataforma web de anotação linguística de transcrições de fala, desenvolvida para o
Trabalho de Conclusão de Curso.
Este repositório reúne o código da plataforma e os dados da anotação de transcrições
automáticas do **NotebookLM** e do **Whisper large-v3** em entrevistas do programa Roda Viva.

🔗 **Acesse o Anotador:** https://anotadorling.lovable.app

## Sobre o Anotador

- Anotação manual de transcrições com categorias personalizáveis (nome, cor, atalho e opção de comentário);
- Mais de uma categoria por trecho (anotação sobreposta);
- Vídeo do YouTube incorporado ao lado do texto;
- Importação de anotações prévias por código de cor;
- Exportação das anotações em CSV, incluindo o formato Key Word in Context (KWIC), e estatísticas por categoria. 
- O Anotador Linguístico disponibiliza a exportação do texto anotado contendo as etiquetas aplicadas, acompanhado ou não de um apêndice. 
- A plataforma possibilita a exportação integral dos projetos desenvolvidos.

## Os dados

- **Corpus:** 3 entrevistas de economia do Roda Viva, cada uma transcrita pelo NotebookLM e pelo Whisper large-v3 (sem prompt)
- **Tipologia:** 16 categorias no documento csv.

> Os arquivos contêm apenas trechos curtos (ocorrência e contexto) das transcrições, e não as transcrições completas. O áudio e o conteúdo das entrevistas pertencem aos seus titulares originais (TV Cultura).

## Observação

Resultados preliminares, com 3 entrevistas anotadas.
